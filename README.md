# Java-Sorting-Algorithms
Java benchmark comparing Selection, Bubble, Insertion, Merge, Quick, and Heap Sort using artist CSV data.


# Java Sorting Algorithm Benchmark

This project compares the performance of several sorting algorithms using a dataset of music artists.

The program reads artist information from a CSV file, converts artist IDs into values that can be sorted, and measures the execution time of each sorting algorithm using `System.nanoTime()`.

## Sorting Algorithms
- Selection Sort
- Bubble Sort
- Short Bubble Sort
- Insertion Sort
- Merge Sort
- Quick Sort
- Heap Sort

## Features
- Reads artist data from a CSV file
- Uses an Artist class to store artist information
- Tests multiple sorting algorithms
- Measures execution time for each algorithm
- Compares performance across different dataset sizes
- Restores the original data between tests so each algorithm sorts the same input
